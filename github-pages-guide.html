🚀 איך מעלים לגיטהב ומפרסמים אתר

המדריך המלא — מאפס עד אתר חי באוויר

1

יוצרים Repository חדש בגיטהב

נכנסים לגיטהב, לוחצים על "New Repository", נותנים שם ולוחצים Create.

GitHub.com → + → New Repository → Create
2

מעלים את הקבצים מהמחשב

פותחים Terminal בתיקיית הפרויקט ומריצים:

# מאתחלים Git בתיקייה
git init
git add .
git commit -m "first commit"

# מחברים לגיטהב
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
3

מפרסמים את האתר (GitHub Pages)

הולכים להגדרות הריפו ומדליקים את GitHub Pages:

Repository → Settings → Pages
→ Source: main branch
→ Folder: / (root)
→ Save ✅

אחרי כמה דקות האתר עולה לאוויר:

https://USERNAME.github.io/REPO/
4

מעלים עדכונים (בכל זמן)

כל פעם שמשנים משהו — שלוש פקודות וזה באוויר:

git add .
git commit -m "תיאור השינוי"
git push
📁

מבנה תיקייה לדוגמה

my-site/
├── index.html ← הדף הראשי (חובה!)
├── style.css ← עיצוב
└── script.js ← קוד
⚡

סיכום מהיר

פקודהמה עושה
git initמאתחל Git
git add .מוסיף את כל הקבצים
git commit -m "..."שומר שינויים
git pushמעלה לגיטהב
Settings → Pagesמפרסם אתר

✅ יתרונות

  • חינם לגמרי
  • HTTPS אוטומטי
  • CDN מהיר עולמי
  • מתעדכן אוטומטי
  • אפשר דומיין אישי

❌ מגבלות

  • אין Backend
  • אין מסד נתונים
  • עד 1GB לריפו
  • הקוד ציבורי (חינם)
  • עד 100GB תעבורה/חודש
💡 טיפ: אם צריכים Backend (שרת, מסד נתונים, לוגין) — שווה להסתכל על Vercel או Netlify. גם שם יש תוכנית חינמית.
